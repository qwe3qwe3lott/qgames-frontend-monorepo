# Docker, nginx и локальный вход через Google

Справочник к CLAUDE.md §10: читать, когда трогаешь `docker/`, nginx, CSP, `docker-compose.yml` или настраиваешь Google-вход локально.

- Вход через Google локально: в Google Cloud Console настроить OAuth consent screen (External, Testing, себя — в Test users), создать OAuth client ID типа Web application с Authorized JavaScript origins `http://localhost:3000` и `http://localhost` (redirect URI не нужны). Client ID прописать в `GOOGLE_CLIENT_IDS` (`.env` бэкенда, затем `docker compose up -d`) и в `PUBLIC_GOOGLE_CLIENT_ID` (`apps/portal/.env`).
- Прод-сборка в Docker: `docker compose up --build -d --wait` — один сервис `web` на nginx (`nginxinc/nginx-unprivileged:1.30.6-alpine`, не от root): статика обоих приложений, по server-блоку на приложение (portal :3000, admin :3001), и reverse proxy на бэкенд `API_UPSTREAM` (по умолчанию `host.docker.internal:8080`). В upstream попадает только IPv4-адрес `API_UPSTREAM` (`docker/nginx/18-api-upstream-ipv4.envsh`: `host.docker.internal` с `host-gateway` резолвится и в IPv6, а подключение по нему из контейнера падает — 502); upstream из одного сервера nginx не помечает недоступным. Портал проксирует `/api/` кроме `/api/admin/` (404), админка — только `/api/admin/` (прочие `/api/` → 404). Конфиг — шаблон `docker/nginx/web.conf.template` (envsubst при старте контейнера: `PORTAL_LISTEN`/`PORTAL_SERVER_NAME`, `ADMIN_LISTEN`/`ADMIN_SERVER_NAME`, `API_UPSTREAM`; по умолчанию 3000/`_`, 3001/`_`) и сниппеты `api-proxy.conf`, `spa.conf`. Прокси: HTTP/1.1, пустой `Connection`, `proxy_buffering off` (SSE без задержек), `proxy_read_timeout 60s` (ping потоков — 5 с), `Host` и `X-Forwarded-*` клиента. Образ — `docker/app.Dockerfile` (сборка на `node:24.22.1-alpine`, мажор как в `.nvmrc`, обновлять вместе). Заголовки на уровне server с `always` (`add_header_inherit merge` — location их дополняет) на всех ответах, включая ошибки и API: `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options` (дубли от Spring скрываются `proxy_hide_header`) и CSP: `default-src 'self'`, `script-src` строгий; у портала — плюс Google GIS (`script-src https://accounts.google.com/gsi/client`, `frame-src`/`connect-src https://accounts.google.com/gsi/`) и `style-src 'unsafe-inline'` (inline-стили ставят GIS и `react-remove-scroll` Radix Dialog/Select); у админки — без Google и без `unsafe-inline` (поэтому стили Sonner подключены файлом в `globals.css`: `<style>`, который Sonner вставляет сам, CSP админки блокирует — в консоли это безвредные ошибки CSP). `/static/*` — `immutable` (не на 404, несуществующий ассет — 404), страницы — `no-cache`, gzip только у статики. `mem_limit 48m` = `memswap_limit 48m` (без свопа); замер: простой ~14 MiB, 360 SSE 5 мин — пик ~29 MiB, 200 SSE и 600 запросов — ~22 MiB. Переменные `PUBLIC_*` вшиваются при сборке из `apps/<app>/.env` (нет файла при наличии `.env.example` — сборка падает); после правки `.env` — `--build`. Бэкенд в этот compose не входит. TLS — решить при деплое.
